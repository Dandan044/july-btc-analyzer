## 完整流程

### 入口一：定时扫描

```
cron → scanner-runner.sh
  ├── scanner-full.py → 命中 COIN
  ├── stage1-prep.js → 预处理
  └── cron add → LLM:
        ├── stage1-v2.md (sentiment)
        ├── gen-stage1-manifest.js
        ├── stage2.md (分析 + JSONs)
        ├── stage3-executor.js (仓位)
        └── stage4-executor.js (规则)
```

### 入口二：警报触发

```
trigger() → stage1-instant.js (采集+派发)
  └── cron add → LLM:
        ├── stage2.md
        ├── stage3-executor.js
        └── stage4-executor.js
```
