# [2026-05-17] set-alert.md 模板收敛重构

## 背景

`set-alert.md` 是警报规则模板文件，由阶段四（警报管理）读取并用于创建引擎规则。最初设计了 7 个模板以赋予 LLM 最大自由度，覆盖多价位、非价格、定时器、延迟触发等多种模式。

长期运行后发现实际使用的模板仅 2 个：多价位延迟确认（~90%）和非价格指标（~10%）。其余 5 个模板从未被实际使用。每次需要修改模板时，改动必须同步到 7 个模板中，导致维护成本线性膨胀。

同时在运行过程中陆续在模板文件中追加了 23 个强制性补丁（禁止 return false、必须用 K 线区间、禁止 execSync 等），这些补丁以文字规则的形式散落在文件的 §3 章节中，部分与模板代码本身不一致（如 §2 基础模板仍使用 `getTicker()` 瞬时价格，违反了 §3.3 的 K 线区间要求）。

## 症状

| 现象 | 数据 |
|------|------|
| 文件总行数 | **1,784 行** |
| 完整代码模板 | **7 个**（有效 2 个，冗余 5 个） |
| 节号冲突 | `§3.2` 出现 **3 次**（价格限制 / 禁止 FGI / 异步触发） |
| 必须/禁止关键词 | **54 处**，分散在全文 |
| 「生命周期由引擎管理」 | **4 处**重复 |
| 模板间不一致 | §2 和 §7 用 `getTicker()`，违反 §3.3 要求的 K 线区间 |
| 修改成本 | 改一处模板逻辑 → 需同步 7 个文件位置 |

## 根因分析

### 根因 1：模板设计从「发散」出发，缺少「收敛」机制

最初设计原则是给 LLM 最大自由度，模板是功能枚举而非决策树。但实际使用中，LLM 在阶段四的约束下（价位数量限制、延迟确认要求）几乎总是选择多价位延迟确认模板。多余的模板成为纯粹的历史债务。

### 根因 2：补丁叠加，无结构整理

23 个补丁分布在以下位置：

| 域 | 补丁数 | 原始位置 |
|----|--------|---------|
| 错误处理 | 3 | §3.0 + §2 清单 |
| 数据获取 | 5 | §3.3 + §0 + §2 清单 |
| 禁止项 | 4 | §3.2(x2) + §3.2.1 + §4 |
| 触发机制 | 3 | §3.2 + §14 + §B.6 |
| 警报设计 | 4 | §3.2 + §3.4 + §3.5 |
| 日志/命名/杂项 | 4 | §3.1 + §4 |

每个补丁都是踩坑后以文字段落追加，从未整合到模板代码本身，导致「读规则才知道约束，看模板却看不到约束实现」。

### 根因 3：主辅标签冗余

模板中添加了「主模板」「辅助模板」及占比说明（~90%/~10%），但上下文流程（阶段四）已经完成了模板选择决策，`set-alert.md` 只需提供模板代码，无需重复决策逻辑。

### 补丁融入验证

23 个补丁整理为 18 条合规项。每条的满足方式从「文字规则」改为「模板代码本身」，确保 LLM 复制模板后自然合规：

| # | 约束 | 融入位置 |
|---|------|---------|
| C1 | catch 必须 throw | 模板所有 catch 块末行为 `throw error` |
| C2 | K 线区间数据 | `check()` 调 `getOKXKlines('1m', 3, 'SWAP')` |
| C3 | 显式传 SWAP | 所有 API 调用显式传 `instType='SWAP'` |
| C4 | 禁止 execSync | `trigger()` 用 `spawn`，数据获取用 `api` |
| C5 | 禁止 FGI | 模板不含 FGI 调用 |
| C6 | 参数类型 | 所有 API 参数均为 string/number |
| C7 | 非空检查 | 模板含 `if (!data) return false` |
| C8 | 异步 spawn | `spawn('openclaw', ['cron', 'add', ...])` |
| C9 | confirmPolicy + confirmMs | `PRICE_LEVELS` 每项均含 |
| C10 | 策略分级 | instant/touch/hold/deep_hold 按价位类型分配 |
| C11 | ≤6 价位 | 模板示例含 6 个价位 |
| C12 | 冷却 ≥1h | `COOLDOWN_MS = 60 * 60 * 1000` |
| C13 | 日志三部分 | `console.log` 含 API 来源 + 进度 + 设立依据 |
| C14 | lifetime() | `return 'active'` |
| C15 | 山寨 trigger 路径 | `[山寨]` 注释标注需改路径 |
| C16 | collect 返回 coin | 模板含 `coin: COIN` |
| C17 | 山寨命名 | `[山寨]` 注释说明文件名格式 |
| C18 | Rubik period | API 参考表中标注 |
