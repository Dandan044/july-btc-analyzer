# 2026-05-30 山寨币/庄币流程统一重构

## 背景

此前 alt（山寨币）和 zhuang（庄币）是两条独立流水线，扫描脚本、阶段任务文件、stage3 执行器均存在大量重复代码。庄币流水线一度暂停。本次重构将两者统一为参数化画像系统。

## 扫描层

- `scanner-full.py` → 统一扫描引擎，`--profile alt|zhuang` 切换画像
  - alt：24h ticker 涨跌幅排序，上限 50
  - zhuang：4h candle 两步法精算，成交量粗筛 + OI+涨跌幅+24h+BTC偏离度 四因子加权
- `scanner-zhuang.py` → 删除（逻辑合入 scanner-full.py）
- `scanner-zhuang-runner.sh` → 删除（scanner-runner.sh 加 --profile 参数）
- crontab 更新：alt `*/30` + zhuang `5 * * * *`，调用同一个脚本
- OI 筛选脚本 → 从纯 OI 排序改为归一化加权综合分

## 阶段一

- `tasks/pipeline/stage1.md` → 新建，alt/zhuang 双画像统一阶段一
- `alt-intel-stage1-v2.md` → 删除
- `zhuang-intel-stage1-v2.md` → 删除
- `alt-intel-sentiment.md` → 删除
- dispatch 消息加入 `画像: {PROFILE}` 字段

## 阶段二：模块化重构

- 两个 40KB 的 stage2.md → 拆分为 9 个模块 + JSON 清单组装系统
- `tasks/pipeline/modules/` — 7 个共享模块 + 2 个画像专属模块（02-止损仓位计算）
- `tasks/pipeline/profiles/` — 分析框架、核心要求、变量定义
- `tasks/pipeline/manifest-{profile}.json` — 组装清单，控制模块顺序
- `scripts/assemble-stage2.js` — 组装脚本，支持 `{{var}}` + `{{include:xxx}}` + `{{#flag}}` 语法
- 组装在 dispatch 前运行时执行（16ms），LLM 读到完整文件
- zhuang 的 02-止损仓位计算 补全了 alt 版有的偏移说明、仓位公式、输出示例等段落

## 阶段三

- `stage3-executor-zhuang.js` → 删除（~1000 行）
- zhuang 版升级为 alt 最新逻辑（市场快报、板块映射、杠杆读取）

## 阶段四
