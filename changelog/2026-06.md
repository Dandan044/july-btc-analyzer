
## 2026-06-10 — 搜索引擎迁移：DuckDuckGo → SearXNG

**背景：** DuckDuckGo 从 6 月 10 日起全面返回 bot-detection challenge，
5 次退避重试全部失败，sentiment-media 采集降级为 kimi_fetch/web_fetch 单页抓取。

**方案：** 自建 SearXNG 元搜索引擎（Docker 容器），聚合 Bing/Yahoo/Brave/Wikipedia 等引擎。

**部署内容：**
- `apt install docker.io` — Docker 引擎
- `docker run searxng/searxng` — SearXNG 容器（localhost:8888）
- `~/.config/searxng/settings.yml` — 引擎配置（禁 Google/DDG，保留 Bing/Brave/Yahoo/Wikipedia）
- `openclaw.json` — `tools.web.search.provider: "searxng"`, `plugins.entries.searxng.config.webSearch.baseUrl: "http://127.0.0.1:8888"`
- `.bashrc` — Docker 自启脚本（WSL2 无 systemd）

**引擎配置：**
| 引擎 | 状态 | 原因 |
|------|------|------|
| Bing | ✅ | 稳定 |
| Brave | ✅ | 稳定（单发） |
| Yahoo | ✅ | 稳定 |
| Wikipedia | ✅ | 最稳定 |
| Google | ❌ | 反爬封 IP |
| DuckDuckGo | ❌ | CAPTCHA |

**并发限制：** 同一代理 IP 并发 > 2-3 触发限流（180s）。实际 pipeline 串行处理不受影响。

**弃用：** Exa（已有 key 但未启用）作为候选备份方案。

**文件变更：**
- `~/.openclaw/july-btc-analyzer/TOOLS.md` — Web Search 节整体替换
- `~/.openclaw/openclaw.json` — provider: duckduckgo → searxng
- `~/.openclaw/openclaw.json.bak.*` — 修改前备份
