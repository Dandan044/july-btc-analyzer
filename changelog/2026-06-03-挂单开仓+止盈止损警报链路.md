# 2026-06-03 — 山寨币流程：挂单开仓 + 止盈止损警报链路

## 背景

阶段三原来只支持市价单直接开仓。对于「突破追多」「抄底做多」「高位做空」「追空」四种入场意图，需要等价格走到位后才手动介入。需要新增挂单机制，让模型能下达条件单/限价单，成交后自动设止盈止损。

## 实测验证

| 测试项 | 命令 | 结果 |
|--------|------|------|
| 限价单 | `swap place --ordType limit --px 1` (SOL@$75) | ✅ 成功挂单 + 附带 TP/SL 可用 |
| 条件单-突破追多 | `swap algo place --ordType conditional --slTriggerPx=75` | ✅ 触发即开仓 |
| 条件单-附带 TP/SL | 同单同时设 slTriggerPx + tpTriggerPx | ❌ tpTriggerPx 被忽略 |

**结论**：条件单的 TP/SL 参数独占于入场触发，不能兼做出场止盈。止盈止损需通过警报引擎拉起即时分析来补设。

### 核心机制

#### 1. 三种开仓方式

| order_type | 命令 | 适用场景 |
|:---------:|------|---------|
| `market` | `swap place --ordType market` | 立即入场（默认） |
| `limit` | `swap place --ordType limit --px 挂单价` | 抄底做多 / 高位做空 |
| `conditional` | `swap algo place --ordType conditional` | 突破追多 / 追空 / 抄底 / 高空 |

限价单可附带 TP/SL（成交后自动激活）。条件单仅触发入口，触发后走警报链路补设止盈止损。

#### 2. 条件单触发参数自动推导

不需手动指定 `slTriggerPx`/`tpTriggerPx`，脚本根据 direction + trigger_price vs 市价自动计算：

```
Long  + trigger > 市价 → slTriggerPx  (突破追多)
Long  + trigger < 市价 → tpTriggerPx  (抄底做多)
Short + trigger > 市价 → tpTriggerPx  (高位做空)
Short + trigger < 市价 → slTriggerPx  (追空)
```

#### 3. 规则 D — 挂单入场 notify 警报

条件单/限价单挂出后，`create_rules` 的 `price_levels` 中必须包含一个 `entry_trigger + notify` 价位，价格 = 触发价/限价。

```
条件单挂出 → 价格触及 → notify 触发 → 拉起即时分析 → 设 OCO
```

此价位 `confirmPolicy: touch`（触及即唤起），不计入 ≤6 个上限。
