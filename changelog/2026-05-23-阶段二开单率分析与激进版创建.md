## 变更 1：阶段三 TP2 拆分修复

### 问题

`stage3-executor.js` 中 `executeOpen()` / `executeAdd()` / `executeAdjust()` / `executeReduce()` 只下一笔 OCO 单，`--tpTriggerPx` 只用了 `tp1Offset`，`tp2` 变量从未写入任何 API 命令。

### 修复

四个函数改为将仓位拆成两笔 OCO 单：

- OCO1：`sz × tp1Ratio/100` → TP1 + SL
- OCO2：剩余张数 → TP2 + SL
- 无 TP2 时回退整单一笔（向后兼容）

### 受影响持仓

| 币种 | 旧状态 | 新状态 |
|------|--------|--------|
| INJ long 45 张 @ 5.346 | 1 OCO: TP=5.981 | 2 OCO: 22张 TP=5.967 + 23张 TP=6.442, SL=4.93 |
| NEAR long 1.1 张 @ 2.088 | 1 OCO: TP=2.289 | 2 OCO: 0.5张 TP=2.289 + 0.6张 TP=2.479, SL=1.874 |

### 残余清理

旧 OCO 单（因前期脚本 bug 产生 2 份残留）全部取消后重新设置。
