# [2026-05-15] 讯飞/astroncodingplan 错误分类 Fallback 补丁

## 背景

astroncodingplan（讯飞）是七月的默认主模型。讯飞 provider 有多种特有错误类型——WebSocket EOF、引擎繁忙、系统繁忙、额度耗尽——这些错误在 OpenClaw 自带 fallback 系统中未被识别，导致子会话直接失败而非自动切换到备选模型（DeepSeek / MiniMax）。

扫描七月所有会话历史，共发现 6 种未被覆盖的讯飞错误，累计影响超过 100 次会话。

## 症状

| 现象 | 数据 |
|------|------|
| 子会话因 WebSocket EOF 直接失败 | 9 次（code 10010 `call CBM fail`） |
| 子会话因引擎繁忙直接失败 | 11 次（`RecvFromEngineError:Engine Busy`） |
| 子会话因系统繁忙直接失败 | 24 次（`EngineInternalError:The system is busy`） |
| 子会话因额度耗尽直接失败 | ~50 次（`NotEnoughCvError`） |
| **合计未正确 fallback 的会话** | **~94 次** |

这些失败直接导致：日报/即时分析任务中断、警报触发后无法生成分析、用户无感知（无声失败）。

## 根因分析

| 错误 | code | OpenClaw 原始分类 | 实际应分类 | 原因 |
|------|------|------------------|-----------|------|
| `call CBM fail` (WebSocket EOF) | 10010 | 未识别 → 直接失败 | `timeout` → fallback | 不在 `INTERRUPTED_NETWORK_ERROR_RE` 正则中 |
| `RecvFromEngineError:Engine Busy` | 10010 | 同上 | `timeout` → fallback | 同上 |
| `EngineInternalError:The system is busy` | 10012 | 同上 | `timeout` → fallback | 同上 |
| `NotEnoughCvError` | — | 未识别 → 直接失败 | `billing` → fallback | 不在 `isBillingErrorMessage` 正则中 |

已有的 code 10012 429/403 错误被 HTTP 状态码层和 auth 分类正常识别，不受此问题影响。

## 修复内容

### 架构改动

| 文件 | 行号 | 改动 | 原因 |
|------|------|------|------|
| `errors-CZgkAaRj.js` | L258 | `INTERRUPTED_NETWORK_ERROR_RE` 正则扩展，新增 8 个模式 | 覆盖讯飞 WebSocket/引擎/系统错误 |
| `errors-CZgkAaRj.js` | L332 | `isTimeoutLikeError()` 中加入同正则可选匹配 | 双保险：网络错误检测层也认这些模式 |
| `errors-CZgkAaRj.js` | L511 | `classifyFailoverClassificationFromMessage()` 中 `billing` 分支追加 `NotEnoughCvError` 正则 | 额度耗尽归类为计费错误 |
| `errors-CZgkAaRj.js` | L520 | `classifyFailoverClassificationFromMessage()` 中 `timeout` 分支追加 `INTERRUPTED_NETWORK_ERROR_RE` 检查 | WebSocket/引擎/系统错误归类为超时 |

### 新增正则模式（L258）

```
\bunexpected\s+EOF\b           — WebSocket EOF
\babnormal\s+closure\b         — WebSocket 1006
\bwebsocket:\s*close\b         — WebSocket 关闭
\bcall\s+CBM\s+fail\b          — Xunfei CBM 失败
\bEngine\s+Busy\b              — Xunfei 引擎繁忙
\bRecvFromEngineError\b        — Xunfei 引擎错误
\bEngineInternalError\b        — Xunfei 内部错误
\bThe\s+system\s+is\s+busy\b   — 系统繁忙
```

## 运维操作

| 操作 | 执行内容 |
|------|---------|
| 扫描历史错误 | 检索七月全部会话历史，按 Xunfei 错误 code 分类统计 |
| 重启网关 | `systemctl --user restart openclaw-gateway.service`（SIGUSR1 不重载 JS 代码） |

## 效果

全部 6 种讯飞特有错误被正确分类并触发 fallback 链：

```
code 10010 → timeout → fallback → DeepSeek V4 Flash
EngineInternalError: system busy → timeout → fallback → DeepSeek V4 Flash
NotEnoughCvError → billing → fallback → DeepSeek V4 Flash
```

七月的 fallback 链：astroncodingplan → deepseek-v4-flash → deepseek-v4-pro → MiniMax-M2.7 → M2.7-highspeed → M2.7-Lightning
