# [2026-05-16] 移除 [SPAWN_INSTANT_ANALYSIS] 冗余 spawn 机制

## 背景

`[SPAWN_INSTANT_ANALYSIS]` 前缀是警报触发即时分析任务的旧设计：规则触发后通过 `cron add` 发送包含此前缀的消息，主会话收到后识别前缀再 spawn 子会话执行分析。该设计假设消息送达主会话，需通过 spawn 保持续响应性。

后来引擎改为 `--session isolated` + `--no-deliver`，消息直接发到 isolated session，不再经过主会话。但 `[SPAWN_INSTANT_ANALYSIS]` 前缀和对应的 spawn 逻辑留在 AGENTS.md 和所有规则中未被清理。

## 问题

isolated session 收到 `[SPAWN_INSTANT_ANALYSIS]{...}...` → 按 AGENTS.md 再 spawn 一个子会话 → 子会话做分析。多了一层无意义的跳转。

## 修复内容

### 架构改动

| 文件 | 改动 | 原因 |
|------|------|------|
| `skills/btc-alert/rules/*.js` (64个) | 删除 `const message = \`[SPAWN_INSTANT_ANALYSIS]...\`` 中的前缀 | 消息直接作为任务内容，无需前缀 |
| `AGENTS.md` | 删除整个 SPAWN_INSTANT_ANALYSIS spawn 区块（含 BTC/山寨币两条分支）及山寨币链路路径二 | 该处理逻辑已无存在意义 |
| `tasks/set-alert.md` | 删除 9 处前缀引用（模板/文档/表格） | 清除过时的设计指引 |
| `tasks/instant-analysis-stage1.md` | 删除 1 处提及 | 同上 |
| `skills/btc-alert/SKILL.md` | 删除 2 处提及 | 同上 |
| `README.md` | 删除 1 行过时说明 | 同上 |

## 未修改

- `rules-archive/`（856 个历史规则文件 — 永不触发）
- `archived/`（历史报告 — 纯文字记录）
- `tasks/archive/instant-analysis.md`（已废弃的任务文件）

## 效果

之前：
```
规则触发 → spawn cron → isolated session 收到 "[SPAWN_INSTANT_ANALYSIS]{...}"
                        → 再 spawn 一个子会话
                        → 子会话做分析
```

之后：
```
规则触发 → spawn cron → isolated session 收到 "{...}\n\n以上为警报触发数据..."
                        → 直接执行分析
```
