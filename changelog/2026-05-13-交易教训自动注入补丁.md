# [2026-05-13] 工作区 TRADE_LESSONS.md 自动注入补丁

## 背景

七月的 `TRADE_LESSONS.md`（原 `LEARNINGS.md`）记录了从复盘和实战中提炼的行为模式——脉冲行情识别、假突破判断时间窗口、风险认知转化等。这些模式需要在七月每次启动时自动加载到上下文中，作为分析师的思维习惯而非流程规则。

OpenClaw 的 workspace bootstrap 注入机制硬编码了五个文件名（AGENTS.md / SOUL.md / IDENTITY.md / USER.md / TOOLS.md），不支持自定义文件。

## 症状

七月每次醒来时，`TRADE_LESSONS.md` 的内容不自动出现在 project context 中。分析报告可能遗忘已提炼的行为模式，导致同类错误重复出现。

## 根因分析

`workspace-Ddypv-c6.js` 中 workspace bootstrap entries 由硬编码数组控制，没有扩展点。新增自定义文件名需要同时修改常量声明、白名单、扫描列表、跳过逻辑四处。

## 修复内容

### 架构改动

| 文件 | 改动 | 原因 |
|------|------|------|
| `workspace-Ddypv-c6.js` L56 | 新增 `const DEFAULT_TRADE_LESSONS_FILENAME = "TRADE_LESSONS.md"` | 常量声明 |
| `workspace-Ddypv-c6.js` L152 | 加入 `VALID_BOOTSTRAP_NAMES` 白名单 | 允许该文件名通过校验 |
| `workspace-Ddypv-c6.js` L460-461 | 加入 entries 扫描列表（排在 MEMORY.md 之前） | 让系统扫描此文件 |
| `workspace-Ddypv-c6.js` L470 | 添加跳过保护：文件不存在时 `continue` | 不影响没有此文件的 agent |
