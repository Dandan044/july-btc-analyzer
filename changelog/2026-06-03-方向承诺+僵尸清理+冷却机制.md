# 2026-06-03 — 山寨币流程：方向承诺 + 僵尸清理 + 冷却机制

## 背景

审计发现 60 个活跃周期中 85%（51 个）处于无持仓观望状态，大量周期生成 15-36 份报告但始终无法做出开仓决策。根因为三：

1. 方向不锚定——模型同时等待做多和做空条件，价格在中间区域震荡时两边都不触发
2. 信号质量不筛选——弱信号周期也进入完整分析流程，产生大量低价值报告
3. 无过期机制——周期无限存活，INIT 8 篇报告 23 小时仍在 wait

### 核心机制

#### 1. 方向承诺（模型侧）

```
首周期：
  步骤一：信号质量底线（总数 ≤3 或高置信度 =0 → abort）
  步骤二：选定 bullish/bearish（4 级递进规则）
  方向选定后 observation_conditions 只朝此方向设置

非首周期：
  验证首篇方向（高置信度 >50% 失效 → abort）
  禁止方向切换——被证伪就终止，不转向
  分析层仍覆盖双向风险，行动层聚焦单方向
```

#### 2. 僵尸自动清理（PM2 进程）

```
每 15 分钟扫描 active/

  筛1: 年龄 > 24h
  筛2: 持仓数 = 0
  筛3: action = "wait"
  筛4: 最新报告在 24h 阈值之后生成（等新报告定生死）

  四筛全中 → archive-cycle.js 归档 + 冷却 72h + 无复盘
```

#### 3. 三条归档路径

| 路径 | 触发者 | 复盘 | 冷却 |
|------|--------|------|------|
| `abort` | 模型（首周期信号不足 / 方向被证伪） | ❌ | ✅ 72h |
| PM2 超时 | cycle-auto-archiver | ❌ | ✅ 72h |
| 常规归档 | stage3 步骤9（平仓后持仓清零） | ✅ 24h后 | ❌ |

#### 4. 冷却机制

- `data/coin-cooldown.json` 由 abort 路径和 PM2 路径自动维护
- `alt-scanner-screening.py` 在窗口扫描筛A阶段检查，冷却期内跳过
- 过期条目在 scanner 读取时惰性清除

### 即时效果

启动首轮扫描即清理 18 个 >24h 僵尸周期：

```

```
