# [2026-05-21] 山寨币阶段二逻辑否定点约束与阶段四止盈止损警报强制化

## 背景

近期归档的仓位中普遍亏损。查看近24小时复盘文件（ENJ、HYPE、KAITO）后发现，三笔交易的方向判断事后均被价格行为验证为正确，但核心问题集中在两个结构性缺陷：

1. **入场逻辑否定点与止损位严重分离**：三笔交易全部命中「逻辑否定点距入场仅 1.1%-1.5%，而止损距入场 6%-6.7%」的模式，导致逻辑被否定后仓位在灰色地带被动持有
2. **计划→执行断层**：止盈计划写在报告中但无自动触发机制（KAITO 的 TP1 被触及但未执行）

## 症状

- ENJ：比值 = 1.1% / 6.74% = 16.3%，逻辑否定点距入场仅 1.1%，止损距入场 6.74%，灰色地带 5.64%
- HYPE：比值 = 1.5% / 6.3% = 24%，逻辑否定点距入场仅 1.5%，止损距入场 6.3%，灰色地带 4.8%
- KAITO：TP1 $0.4326 被价格触及，但仓位未在该处平仓，最终微亏出局

## 根因分析

### 根因一：阶段二缺少逻辑否定点与止损位的统一约束

阶段二的止损位计算完全依赖 `scripts/calc-position.js` 的波动率统计+技术位偏移，但从未与入场逻辑的否定点交叉验证。这导致：

- 脚本偏移到技术位 $0.0491（4H 38.2%回撤）
- 但入场逻辑的否定点是 $0.0456（4H 61.8%回撤突破）
- 两者分离，创造巨大灰色地带

### 根因二：阶段四未强制要求设定止盈止损价位警报

阶段四的警报管理流程中，止盈止损价位未被列为「必须包含」的警报候选。KAITO 周期虽然报告明确写了「止盈1 $0.4326（平仓50%）」，但阶段四未设定对应价位警报，导致 TP1 触及时无自动提醒。

### 根因三：TRADE_LESSONS.md 中「动能极端时逆势入场」的教训未被阶段二强制阅读

ENJ 在 4H RSI 75、1H RSI 76、OI +43% 时逆势做空，该教训已写入 TRADE_LESSONS.md，但阶段二流程中未强制要求阅读。

### 逻辑否定点统一约束规则

```
比值 = 逻辑否定点距离% / 最终止损%

| 比值 < 0.5    | ❌ 放弃 | 灰色地带过大 |
| 0.5 ≤ 比值 ≤ 1 | ✅ 通过 | 止损位在逻辑否定点外侧合理距离 |
| 比值 > 1      | ⚠️ 偏移 | 向更远技术位偏移止损，重新计算比值 |
```
