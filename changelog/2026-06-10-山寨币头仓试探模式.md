# [2026-06-10] 山寨币头仓试探模式

## 背景

山寨币分析流水线的开仓逻辑是二元的——要么全仓进场（跑 calc-position.js 算 SL+TP），要么观望。当方向判断明确但短期技术面超买/超卖时，模型无法折中：全仓进场止损太宽，观望又可能踏空。H 币即是典型案例。

## 症状

- 多个周期因「方向明确但入场时机不完美」被模型放弃
- 信号充足但 RSI 超买、K 线远离均线——此时全仓进场盈亏比不够 1.2
- 没有「轻仓试探、追踪保护」的中间态

## 根因分析

1. `analysis-alt.md` 的开仓决策树只有 `open(full)` / `wait` / `abort` 三条分支
2. 模型需要方向置信度 + 入场时机质量同时达标才能开仓，这过于苛刻
3. 山寨币的特点是：关键突破往往伴随短期超买（庄家拉盘风格），完美入场时机根本不出现

### 头仓模式规则

| 维度 | 规则 |
|------|------|
| 仓位 | nominal_base × head_ratio（25%-50%） |
| 止损 | 追踪止损（swap algo trail），不设固定 SL |
| 止盈 | 不设固定 TP |
| 证实位 | confirm_price → notify 级警报 → 触发加仓分析 |
| 证伪位 | falsify_price → notify 级警报 → 触发归档（追踪止损应已触发平仓） |
| 监督者 | 不入监督者审查（轻仓 + 追踪止损，风险可控） |

- `stage2-alt.md` — 组装产物，改模块自动生效
