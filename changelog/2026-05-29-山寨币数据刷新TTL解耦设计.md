# 山寨币链上数据刷新 — TTL 解耦（第一阶段：链上）

> 2026-05-29 | 七月 + 主人 | ✅ 已实施

---

## 背景

现有山寨币周期交易系统中，链上数据和媒体数据只在周期启动时采集一次，后续即时分析永远复用。数据生产（采集）和数据消费（分析）耦合在同一触发机制中。

## 核心设计

**数据生产与消费解耦**：链上数据由独立脚本定时刷新（不经过 LLM），阶段二只读取最新本地文件。

```
           cron（每6h，23分偏移）
                │
                ▼
      onchain-refresh-scheduler.js
        扫描 active/ 全部周期
        按 manifest 中 TTL 判断过期
                │
                ▼
      refresh-onchain.js（纯脚本）
        多链搜索 + 并行采集 4 维度
        输出标准化 JSON → data/
        自动更新 manifest 引用
                │
                ▼
           阶段二只需 read JSON
```

## 实施内容

### 1. `scripts/refresh-onchain.js`（核心采集脚本）

- **多链搜索**：ETH+SOL → BSC → Arbitrum → Base → Polygon，评分择最优匹配
- **并行采集 4 维度**：holders / advanced-info / cluster-overview / trades
- **输出标准化 JSON**：8 个顶层块，字段名 `中文(英文)` 格式
- **精简设计**：DEX 聚合统计 + 仅大额交易（中位数×3）、持仓 TOP5、去冗余字段
- **变化检测**：对比上次 JSON，7 条规则全用 0.01 防抖阈值
- **自动更新 manifest**：保存后更新 `data-manifest` 中的 `json_file` 引用
- **异常分类**：ok / partial(solana_limited / bsc_limited) / unsupported / not_found
- **保存路径**：`data/onchain-{COIN}-{YYYYMMDD}-{HHMM}.json`
- **日志**：统一写入 `logs/onchain-refresh.log`

### 2. `scripts/onchain-refresh-scheduler.js`（调度器）

- 单次执行后退出（非 PM2 常驻）
- 扫描 active/ 下所有周期，读取 manifest → 检查 TTL 过期
- 串行执行刷新，退避重试（15s→30s）
- 系统 cron：`23 */6 * * *`

### 3. `scripts/stage1-prep.js`

- 合约数据获取后新增步骤 8：调用 refresh-onchain.js（3 次退避重试：15s→30s→60s）
- 确保周期创建时链上 JSON 即就位

### 4. `scripts/gen-stage1-manifest.js`

- `sentiment_onchain` 新增字段：`json_file`、`json_updated_at`、`json_ttl_minutes`

### 5. `scripts/onchain-batch-backfill.js`（一次性补建脚本）

- 为 49 个老周期批量补建链上 JSON，串行执行，币种去重

## JSON 结构（8 块）

```
元数据(meta)           — 状态、异常类别、有效期
链信息(chain)          — 哪条链、合约地址、搜索路径
市场数据(market)       — 价格、市值、持有人数、流动性
持仓分布(holders)      — 前5% + 前100% + 前5地址明细
风险指标(risk)         — 风险等级、集中度、狙击手标记
集群分析(cluster)      — 新地址占比、同创建时间、同资金源
DEX交易(dex)           — 聚合统计 + 仅大额交易
代币标签(tags)         — 社区认可等
变化标记(changes)      — 对比上次，7 条低阈值规则
```

## 变化检测规则（7 条，全 0.01 防抖）

| 字段 | 条件 |
|------|------|
| 市值 | ≥ 0.01% |
| 持有人数 | ≥ 1 人 |
| 前5持仓占比 | ≥ 0.01pp |
| 前100持仓占比 | ≥ 0.01pp |
| 集群集中度 | Low↔High 翻转 |
| 新地址占比 | ≥ 0.01pp |
| 大额交易数 | 任何变化 |

## 测试结果

| 状态 | 数量 | 代表币种 |
|------|------|---------|
| `ok` | 32 | PENDLE, BILL, COMP... |
| `partial` (Solana/BSC 限制) | 13 | BEAT, GMT, HYPE... |
| `unsupported` (原生链) | 3 | TON, HMSTR, STRK |
| `not_found` (未索引) | 2 | CRCL, USAR |
