### 步骤 {{step_close}}: 阶段二收尾

保存报告 + 输出两份 JSON 后，记录阶段二结束日志：

```bash
NOW=$(date '+%Y-%m-%d %H:%M:%S')
echo "[$NOW] [阶段二] 报告已保存: reports/{{report_prefix}}-{COIN}-YYYY-MM-DD-HHMM.md" >> logs/{{log_prefix}}-${COIN}-process.log
echo "[$NOW] [阶段二] 开仓数据已保存: reports/trade-decision-{COIN}-YYYY-MM-DD-HHMM.json" >> logs/{{log_prefix}}-${COIN}-process.log

echo "[$NOW] [阶段二] ========== 阶段二结束 ==========" >> logs/{{log_prefix}}-${COIN}-process.log
```

输出阶段二完成进度：

```
阶段二交叉验证分析已完成。
币种: {COIN}
周期目录: active/{CYCLE_DIR}
报告已保存: reports/{{report_prefix}}-{COIN}-YYYY-MM-DD-HHMM.md
开仓数据已保存: reports/trade-decision-{COIN}-YYYY-MM-DD-HHMM.json
警报候选数据已保存: reports/alert-candidates-{COIN}-YYYY-MM-DD-HHMM.json
```

**⚠️ 收尾之后必须执行阶段三和阶段四脚本（详见下方「🔀 阶段交接」）。** 日志+输出完成不代表规则文件已生成——只有执行阶段三和阶段四脚本后，仓位和警报规则才会实际创建。
