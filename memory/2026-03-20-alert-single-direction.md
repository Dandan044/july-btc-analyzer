# 警报规则：单方向单一警报

**创建时间**: 2026-03-20
**规则来源**: Dandan 指令

## 核心原则

每个方向（向上/向下）**最多只保留一个警报**：
- 向上方向（阻力位突破）：最多 1 个
- 向下方向（支撑位跌破）：最多 1 个
- **总计最多 2 个活跃警报**

## 选择标准

当同一方向有多个警报时，保留**最接近当前价格**的那个：
- 向上方向：保留更近的阻力位
- 向下方向：保留更近的支撑位

## 示例

假设当前价格 84000：
- 已有警报：阻力 92000、支撑 80000
- 发现新阻力 86000 → 归档 92000，创建 86000
- 发现新支撑 82000 → 归档 80000，创建 82000

## 原因

警报触发后，即时分析任务会重新评估市场并设置新警报。多个同方向警报过于敏感，实际上只需要监控最近的上下边界即可。
